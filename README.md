# 💡 Socket.IO Learning – Chatty

This repository is part of my learning journey with **Socket.IO**, where I built a very basic real-time chat application called **Chatty**.

## 📚 About

**Chatty** is a simple one-to-one chat app made using:

- **React (Vite)** for the frontend  
- **Node.js + Express** for the backend  
- **Socket.IO** for real-time WebSocket communication

It was created to help me understand the core concepts of **real-time messaging**, **WebSocket events**, and basic client-server architecture.

---

## 🛠 Tech Stack

- React (Vite)
- Node.js + Express
- Socket.IO
- nanoid (for generating unique user IDs)
